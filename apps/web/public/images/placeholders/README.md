# Placeholder images

This folder holds neutral placeholder assets used when a real image is not
available yet, without fabricating content.

Rules:

- Placeholders must be visually obvious as placeholders. They must not
  imitate a real organization logo, real user avatar, or real opportunity
  image.
- No fake statistics, no fake logos, no fake people.
- Every placeholder is a small SVG. No binary assets are committed here.

Expected files (add as needed):

- organization-placeholder.svg
- user-placeholder.svg
- opportunity-placeholder.svg
- document-placeholder.svg
